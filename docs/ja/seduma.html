03仕組み

四つの平易な手順。まず Practice。

Seduma は戦略を同梱しません。ルールはあなたが持ち込みます。Seduma は初期状態で Practice において実行し、あなたが言うまで Live には進みません。

  1. 手順 01

    ルールを持ち込む

    戦略とは、いつ注文を出すかを決める規則の集まりです。あなたが自分の規則を持ち込みます。Seduma は取引を選ばず、推奨せず、生成もしません。

  2. 手順 02

    Practice から始める

    Practice が初期の開始点です。約定はシミュレートされ、実資金は動きません。最初の Practice 実行に、Live の鍵も実際のブローカーの鍵も要りません。

  3. 手順 03

    止め方を知る

    緊急停止は、あなたが解除するまで、Seduma に新規注文の送信を拒否させます。未決済ポジションは決済せず、すでにブローカーにある注文も取り消しません。

    Seduma は監査記録を残します。外部サービスに連絡する前に書かれる記録です。

  4. 手順 04

    Live は、選ぶ場合だけ

    Live は任意で、初期状態ではオフです。セットアップを終えてもオンになりません。Live を選ぶには、LIVE と入力して自分で確認します。勝手にはオンになりません。

    緊急停止は Practice でも Live でも利用できます。未決済ポジションは決済しません。

初回実行

セットアップは Paper のままです。

初回セットアップは四段階です。Paper Practice へようこそ、安全確認、練習実行を試す、そして 準備完了 — セットアップは Paper のまま。

安全確認は、Paper の開示を読んだことを記録します。Live はオンにしません。セットアップを終えても Live はオンになりません — 選ぶのは後です。

Live の選択

Live は選択であり、初期状態ではありません。

Live を選ぶ場合でも、すべての項目に印が付き LIVE が入力されるまで、Seduma はオンにしません。取り消すと Practice のままです。

ブローカーを接続しても Live は解除されません。緊急停止は Practice でも Live でも利用できます。未決済ポジションは決済しません。
