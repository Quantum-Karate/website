Seduma™ · 事実

Seduma™ とは何か、何でないか

平易な事実を、平易な言葉で。限界も含みます。

Seduma™ は

  1. Paper から始まり、戦略を同梱しない実行環境。あなたが持ち込む取引ルールを、Practice から実行するソフトウェア。
  2. 初期状態は Practice。Paper が初期の開始点です。実注文の送信は初期状態でオフです。
  3. あなた自身の戦略を中心にしています。戦略 — いつ注文を出すかを決める規則 — はあなたが持ち込みます。
  4. Live は、あなたが選ぶときだけ。Live は、あなたが選び、確認が必要な手順を経たときに使えます。セットアップを終えても Live はオンになりません — 選ぶのは後です。
  5. 緊急停止を備えています。緊急停止は Practice でも Live でも利用できます。未決済ポジションは決済しません。
  6. 外部への依頼の前に記録します。Seduma は監査記録を残します。外部サービスに連絡する前に書かれる記録です。
  7. あなたが定めるリスク限度を使います。リスク限度はあなたが設定します。
  8. 持ち込む接続に開かれています。組み込みの接続は便宜であり、排他的な一覧ではありません。利用できる別の API を持ち込めます。
  9. ブローカーの鍵なしで練習できます。最初の Practice 実行に、Live の鍵も実際のブローカーの鍵も要りません。
  10. 一度きりの Dojo。$49、一度きり、サブスクリプションなし、解約するものはありません。購入者は Neural Agency Engine を含むソースを受け取り、自分のコンピュータで実行します。

Seduma™ は次ではありません

  1. ブローカー。Seduma はブローカーではありません。
  2. 投資助言業者。Seduma は投資助言業者ではありません。取引を選ばず、推奨せず、生成もしません。
  3. 戦略の供給元。戦略を同梱しません。戦略の市場でもありません。
  4. あなたが言う前の取引。あなたがそう言うまで取引しません。Seduma を導入しても、セットアップを終えても、ライブ注文は出ません。
  5. 結果の約束。Paper/Practice の P&L は Live の結果の約束ではありません。Practice の約定はシミュレートされたものであり、Live の約定ではありません。結果はシミュレートされたものだけです。不労所得の約束はなく、利益の約束もありません。
  6. 接続すれば解除されるもの。ブローカーを接続しても、接続を読み込んでも、Live は解除されません。
  7. 自動決済。緊急停止は未決済ポジションを決済せず、すでにブローカーにある注文も取り消しません。
  8. Neural Agency Engine。Seduma が入口です。Neural Agency Engine は調査エンジンです。取引を選ばず、推奨せず、Live のスイッチでもありません。

—用語

使う言葉。

Practice
シミュレートされた約定で取引ルールを動かすこと。実資金は動きません。Seduma では Practice が初期状態です。
Paper
Practice の別の言い方です。
Real paper
ブローカー自身のペーパー口座。それでも実資金はありません。
Live
あなたが設定した接続を通して送る、実注文と実資金。Seduma では、自分で選ぶまで Live はオフです。
確認が必要（confirm-gated）
自分で確認するまで効力を生じない手順。Live については、すべての項目に印が付き LIVE が入力されるまで、Seduma はオンにしません。
約定（fill）
注文が成立する瞬間と、その成立価格。Practice では約定はシミュレートされます。
P&L
取引の累積の利益または損失。Paper/Practice の P&L は Live の結果の約束ではありません。
戦略（strategy）
いつ注文を出すかを決める規則。あなたが持ち込みます。Seduma は供給しません。
接続（connection）
Seduma から、あなたが利用できる取引プラットフォームへのリンク。Real paper、Test sandbox、または Live に対応と表示されます。
緊急停止（emergency stop）
Seduma に、解除するまで新規注文の送信を拒否させる操作。Practice でも Live でも利用できます。未決済ポジションは決済せず、すでにブローカーにある注文も取り消しません。
監査記録（audit trail）
外部サービスに連絡する前に Seduma が書く記録。Seduma 自身のログであり、独立した監査ではありません。
