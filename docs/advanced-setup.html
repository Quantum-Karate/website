Advanced setup

Optional steps for the Neural Agency Engine paper stack, the results-page console token, and importing your own backtest numbers. The regular install and Practice steps stay on the Guide.

01Docker

Docker (optional)

Docker is not used for the Practice console. It is for the optional Neural Agency Engine paper stack (Redis and the engine’s agents, all set to paper and sandbox). You need Docker Compose 2.20 or newer.

cd Seduma_Trade/seduma/nae-integration
cp .env.example .env
./scripts/install.sh
./seduma start

The first run of install.sh creates your .env and stops. Run it a second time to finish setup, then start. On Windows use powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 and .\seduma.cmd start. Keep NAE_ENVIRONMENT=paper in .env. Useful commands: ./seduma status, ./seduma logs, ./seduma stop.

02Console token

Apply the results-page console token

You read practice results on the Neural Agency Engine console, which is a separate page from Practice. Start it from the seduma/nae-integration folder:

cd Seduma_Trade/seduma/nae-integration
pip install -r requirements-console.txt
python -m web_console

Use the same Python 3.11 or newer environment you installed Seduma Trade into. Then open http://127.0.0.1:8745/practice-results.

The console prints where your access token is stored (a file named console.token in a .seduma folder). Paste that token into the page’s “Console token” box and press Apply. Keep the token private. This page only runs on your own computer.

03Backtest import

Import your own backtest numbers

This step is optional. It is not required to practice or to read your simulated results.

Have backtest numbers of your own? Import a CSV or JSON file to see them next to your practice results. A large gap shows “results differ from backtest, check assumptions”.
